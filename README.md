# Conceptic User Management API

>  **Projet en évolution**
>
> Ce projet fait actuellement l'objet d'une refonte architecturale progressive visant à améliorer la maintenabilité, la qualité du code, la couverture des tests et la scalabilité de l'application.
>
> La branche **`refactor/v2`** constitue la nouvelle architecture de référence et continue d'intégrer des améliorations et optimisations. Les principales évolutions sont documentées au fur et à mesure de leur intégration.

Ce projet est une API REST de gestion d'utilisateurs développée avec **Laravel 11**...
